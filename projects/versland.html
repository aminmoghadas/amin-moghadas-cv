Versland

Senior WordPress developer at Versland — custom plugins reading real-time crypto pricing from exchange APIs, a rebuilt widgets plugin, and performance work across the site.

Visit versland.io →

Context

Versland is a cryptocurrency exchange whose marketing site needed something WordPress doesn't ship with: real-time pricing data feeding live widgets across the site. I built a custom plugin that reads prices from exchange APIs into the database with proper site-side rendering, so the page stays fast even with constantly-updating data.

Beyond the pricing engine, I rebuilt their broken widgets plugin from scratch and shipped performance optimizations across the site. The engagement ran for 9 months.
