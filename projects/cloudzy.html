Cloudzy

Senior WordPress developer at Cloudzy — building custom Elementor widgets, internal SEO tooling, and leading the long-term migration from Elementor to native Gutenberg blocks.

Context

Cloudzy is a US-based cloud VPS and infrastructure provider with a marketing site spanning 200+ landing pages built on WordPress and Elementor. I joined as a senior developer focused on Elementor widget development, internal SEO tooling, and quietly leading the long-term migration of the company's theme and widget library from Elementor to native Gutenberg blocks — targeting significant performance gains without breaking the editing experience for the content and marketing teams.

Admin features I built

A mix of admin tooling, dynamic widget infrastructure, and integrations — built so the product, content, and SEO teams can ship faster without touching code.
