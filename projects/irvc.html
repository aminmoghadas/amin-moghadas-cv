IRVC

Built a custom WordPress plugin that runs IRVC's entire B2B company directory — from multi-step self-registration to a self-service dashboard for the listed companies.

Visit irvc.ir →

Context

IRVC is a B2B company directory connecting Iranian businesses with the broader ecosystem. The product needed two things: a way for companies to register and pay without admin intervention, and a way for each company to keep its own listing up-to-date after the fact. I built a custom WordPress plugin handling both — a multi-step self-registration flow with integrated payment processing, plus a self-service dashboard where each company manages its own profile.

The plugin also exposes admin oversight tools for the IRVC team. I designed the public site alongside the plugin.
